# 인삼 AI 영농일지 — 앱 설치 안내 (농가용)

이 앱은 구글 플레이스토어가 아니라 **파일(APK)을 직접 설치**하는 방식입니다. 스마트폰이
"출처를 알 수 없는 앱"을 기본적으로 차단하기 때문에, 아래 순서대로 한 번만 허용해주시면 됩니다.
한 번 허용해두면 다음 업데이트부터는 다시 설정할 필요가 없습니다.

## 1. 다운로드

문자나 카카오톡으로 받은 링크를 눌러 `ginseng-farm-app.apk` 파일을 다운로드합니다.
(다운로드 후 화면 상단 알림에 "다운로드 완료" 같은 문구가 뜹니다.)

## 2. "출처를 알 수 없는 앱" 허용하기

기기와 안드로이드 버전에 따라 화면이 조금씩 다릅니다.

### 갤럭시(삼성) 기기 — 가장 많은 경우
1. 다운로드한 apk 파일을 다시 누르면 **"출처를 알 수 없는 앱을 설치하시겠습니까?"** 경고가 뜹니다.
2. **"설정"** 버튼을 누릅니다.
3. **"이 출처 허용"** 스위치를 켭니다. (보통 사용한 브라우저나 "내 파일" 앱 이름으로 표시됨)
4. 뒤로 가서 다시 apk 파일을 누르면 설치가 진행됩니다.

### 일반 안드로이드 (Android 8 이상)
1. apk 파일 실행 → "설치 차단됨" 알림이 뜨면 **"설정"** 클릭
2. **"이 출처 허용"** 켜기
3. 다시 설치 진행

### 구형 안드로이드 (Android 7 이하)
`설정 → 보안 → 출처를 알 수 없는 앱` 항목을 미리 켜두면 됩니다.

## 3. "Play 프로텍트로 인해 차단됨" 경고가 뜨는 경우

구글의 자동 검사(Play 프로텍트)가 "알 수 없는 앱이라 위험할 수 있다"는 안내를 띄울 수 있습니다.
저희 회사가 배포한 정식 앱이니 아래처럼 진행하세요.

1. 경고창에서 **"세부정보"** 또는 **"자세히 보기"** 클릭
2. **"무시하고 설치"** 클릭

## 4. 설치 완료 후

- 홈 화면에 초록색 새싹 아이콘의 **"인삼 AI 영농일지"** 앱이 생성됩니다.
- 처음 실행하면 로그인 화면이 나옵니다. 담당자에게 받은 **전화번호/비밀번호**로 로그인하거나,
  새로 회원가입해 농가를 등록하세요.
- 같은 농가 식구(배우자 등)가 함께 쓰려면, 설정 화면에서 확인되는 **"농가 코드"**를 알려주고
  회원가입 시 "기존 농가 합류"를 선택하게 하면 됩니다.

## 자주 묻는 질문

**Q. "앱이 손상되었습니다" 또는 설치가 안 돼요.**
A. 다운로드가 중간에 끊겼을 수 있습니다. 파일을 삭제하고 다시 받아보세요.

**Q. 이미 설치되어 있는데 새 버전을 받았어요.**
A. 그냥 새 apk를 똑같이 설치하면 기존 앱 위에 업데이트됩니다(데이터 유지). 별도로 지울 필요 없습니다.

**Q. 아이폰(iOS)에서도 쓸 수 있나요?**
A. 아쉽지만 이 방식(파일로 직접 설치)은 안드로이드 전용입니다. 애플은 앱스토어를 거치지 않은
설치를 원천적으로 막아놔서, 아이폰 사용자는 정식 앱스토어 출시 전까지는 이용이 제한됩니다.
아이폰 사용자가 많으면 회사 쪽에 앱스토어 출시 일정을 문의해주세요.
