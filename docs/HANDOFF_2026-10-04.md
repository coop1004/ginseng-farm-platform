## 2. 드롭다운 잘림 버그 (7회 시도 끝에 해결 — 재발 방지용 상세)

- **원인**: `DropdownButtonFormField`의 `isDense` 기본값이 `true`. 이때 닫힌 상태의 선택값 영역에 `max(fontSize, iconSize, kDenseButtonHeight)` 고정 높이가 강제됨. `contentPadding`·`TextStyle.height`·`fontFamily`와 무관해서 앞선 6회 시도(itemHeight, 아이템 패딩, contentPadding 증감, height 2.0, fontFamily)가 모두 무효였음. 또한 `isDense:true`면 `itemHeight:null` 처리도 닫힌 상태에는 적용되지 않음.
- **수정**: 앱 내 10개 드롭다운 전부에 `isDense: false` 추가 (`farm_selector.dart`, `work_log_screen.dart`, `farm_form_screen.dart`×4, `stats_screen.dart`, `diagnosis_screen.dart`×2, `diagnosis_result_screen.dart`). 임시 진단 코드(빨간 테두리/노란 배경/fontFamily 후보)는 제거 완료.
- **규칙**: 새 `DropdownButtonFormField`를 추가하면 반드시 `isDense: false` + `itemHeight: null` + `isExpanded: true`. 에뮬레이터·`flutter analyze`로는 안 보이고 실기기 한글에서만 드러남.
- **정리 필요(선택)**: 6~7번째 시도 중 쓴 `3c7b4fb`/`80c1441`의 `app_theme.dart` `contentPadding`(현재 `fromLTRB(14, 6, 14, 10)`)은 원인과 무관했던 값이라 앱 전역 인풋 모양에 영향을 줌. 의도한 디자인인지 확인하고 필요하면 원래 값(vertical 12)으로 되돌릴 것. 이력에 `[임시 진단]` 커밋 2개(`f2dab44`, `cb12efe`)가 남아 있음(이미 푸시됨, 되돌리지 말 것).

## 3. 환경·기술 메모

- **Android 툴체인이 오래됨**: AGP 7.3.0 / Kotlin 1.7.10 / Gradle 7.6.3. 최신 `speech_to_text`(7.4+)·`flutter_tts`(4.2.5+)는 `flutter.compileSdkVersion` 때문에 빌드 실패 → 현재 `speech_to_text ^6.6.2`, `flutter_tts ^3.8.5`로 고정. 올리려면 AGP/Gradle 업그레이드가 선행돼야 함.
- **speech_to_text 6.6.2**: `localeId`는 `listen()` 최상위 파라미터로 넘겨야 하며, 안드로이드는 BCP-47(`ko-KR`) 형식만 인식. `locales()`가 주는 `ko_KR`는 하이픈으로 치환해야 함 (`voice_note_sheet.dart`에 반영).
- **AndroidManifest**: `RECORD_AUDIO` 권한 + `android.speech.RecognitionService` `<queries>` 필수(Android 11+). **iOS Info.plist**: `NSMicrophoneUsageDescription`과 `NSSpeechRecognitionUsageDescription` 둘 다 있어야 크래시 안 남.
- **GitHub 100MB 파일 제한**: 디버그 APK(약 160MB)는 커밋 금지. 과거 이 때문에 push가 5시간 멈췄고 `git rebase --onto`로 커밋을 제거해 해결함. 설치용 APK는 별도 파일로 관리.
- 최신 디버그 APK(로컬 빌드, 미커밋): `mobile/build/app/outputs/flutter-apk/app-debug.apk`
